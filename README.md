# Nikhilesh Mendhe | Digital Marketing Specialist Portfolio

Personal portfolio website for **Nikhilesh Mendhe**, Digital Marketing Specialist specializing in Performance Ads, Funnel Architecture, and Growth Marketing.

## Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn-ui, Radix UI
- **Icons & Animations**: Lucide React, Tailwind CSS Animate
- **Theme**: Dark theme with neon red accents and theme toggle

## Project Features

- **Hero & Value Proposition**: Highlighting developer-turned-marketer strengths.
- **About & Philosophy**: The 4 pillars of growth: Audience Research, Creative, Funnel, and Measurement.
- **Skills Matrix**: Paid Ads, Analytics & Tracking, Organic & Content, and Creative Tools.
- **By The Numbers**: Animated performance counters.
- **Case Studies**: In-depth breakdowns with Problem, Solution, and Verified Results.
- **Client Testimonials**: Carousel reviews from brand founders and marketing leads.
- **Direct Lead Capture**: Integrated with email delivery and WhatsApp quick-connect.

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run ESLint validation
npm run lint

# Build for production
npm run build
```
